Selected Projects

Phonorama — A pronunciation support tool

Developed with a five-person team in collaboration with Aster Formation for a project management course. The tool compares French phoneme inventories with those of other languages, drawing mainly on PHOIBLE data and displaying consonants and vowels in interactive charts to support pronunciation teaching.

My role: I helped build application features using JavaScript and PHP and worked with the SQLite database. I then migrated the database to MySQL, deployed the app on the university server, fixed how sounds are placed in the charts and redesigned the interface.

Dictation Management — A tool for teachers and researchers

An educational platform where teachers can manage dictations, review student results and explore writing errors. The team combined a PHP/MySQL web application with a Python linguistic analysis pipeline using Stanza and OCR-based text extraction.

ParlaCAP — Classifying parliamentary speeches

A two-person NLP project with Camille Benoit-Guyod, focused on predicting political party labels from French parliamentary speeches. We compared five DistilCamemBERT and CamemBERT configurations, including approaches to class imbalance. Our best reported run reached 56.69% accuracy and 48.29% macro-F1.

What we worked on: preparing the data, fine-tuning Transformer models and evaluating their performance in Python.

Python Transformers

Evaluating Automatic Speech Recognition (ASR)

In a four-person research project, we evaluated TADDDAM's French speech transcripts against manual references from two native and two non-native speakers. Observed Word Error Rates ranged from 9.96% to 19.41%. With only four participants, the results are exploratory rather than generalizable.

What I worked on: text normalization, calculating Word Error Rate (WER), and identifying substitutions, deletions and insertions with Python and JiWER. The public repository contains fictional sample data only.
